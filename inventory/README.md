## Why some names are not links

Only the 87 published records belong to the controlled public baseline. Some transitional website URLs may still resolve while cleanup is in progress. Keeping non-published names visible without linking them avoids treating an automated discovery as a published destination or recommendation.

Snapshot date: 2026-08-17. Source descriptions can change; verify current information on a published plugin's [dshplugin.dev](https://dshplugin.dev/) page and publisher source.
